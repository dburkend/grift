# Grift

Power-focused ERG interval trainer for the Wattbike Atom. No virtual world, no subscription — just power, target, cadence and the clock.

**Open the app:** https://dburkend.github.io/grift/

- **iPhone / iPad:** open the link in the free **Bluefy – Web BLE Browser** app (Safari and Chrome on iOS can't use Bluetooth).
- **Mac / Windows / Android:** open the link in Chrome or Edge.

Everything runs in the browser; workouts and ride history are stored on the device. Rides export as `.tcx` for upload to Strava.

First run: tab 1 → connect the bike → run the guided ERG verification before riding in ERG mode.
