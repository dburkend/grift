# ESPN – Hide Women's Sports

Userscript that hides WNBA, NWSL, women's college, LPGA, PWHL, espnW, and other women's-sports content on ESPN.com: headlines, cards, scoreboard, and nav menu. Opening a women's-sports page sends you back to the homepage.

**Install:** get [Tampermonkey](https://www.tampermonkey.net/) (Chrome/Edge/Firefox/Safari) or the **Userscripts** app (iPhone Safari), then open:

https://raw.githubusercontent.com/dburkend/grift/espn-filter/espn-no-womens.user.js
